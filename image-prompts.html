Reality TV Intel — Image Asset Prompts

Every visual asset the site currently needs, with a ready-to-paste, highly detailed prompt for each. Written to a single consistent visual system (dark background, glowing blue/purple/gold accents, the same "TV studio in space" language as the 3D landing page) so whatever you generate matches everything else, whichever tool you use.

How to use this:
  • Copy a prompt, run it in your image generator of choice, upload the result back here in chat.
  • Each entry lists the exact filename and dimensions the site expects — matching those means it drops in with zero code changes.
  • Prompts deliberately avoid baking in UI text except where noted (banners) — everything else should be a clean image with no lettering, since real text is rendered by the site itself on top.
  • If a generator gives you extra padding/whitespace or an off-ratio result, crop to the listed dimensions before uploading.

Brand & Icons
The core mark everything else derives from. Get this one right first.
1. Primary Logo Icon
logo-icon.png
Size: 512×512px Format: PNG, transparent background Shape: square, safe-area centered (icon should read clearly even cropped to a circle)
Used in: browser tab favicon, nav bar brand mark, Twitch-login-style app icon, apple-touch-icon, OG banners — this is the single most-seen asset on the site, appears at sizes from 16px to 512px.
Prompt
A minimal, modern app icon logo mark for a reality TV analytics and predictions platform called "Reality TV Intel." Dark near-black background (#08080F). The mark itself: a stylized geometric fusion of a television/broadcast signal shape and a rising bar chart, rendered as a glowing crystalline gem or faceted icosahedron shape — angular, low-poly, semi-transparent glass-like material, backlit with an inner glow. Color gradient across the mark from electric blue (#4A9EFF) through violet-purple (#8B5CF6) to warm amber-gold (#F5A623), glowing/emissive, soft outer bloom/glow halo around the edges. Subtle fine particle sparkles scattered around the mark. Style: premium sci-fi UI iconography, similar to a high-end streaming service or esports league logo — NOT cartoonish, NOT a literal TV set illustration, NOT flat 2D corporate clip-art. Sharp, crisp vector-like edges with soft glow, centered composition with generous padding, works at small sizes. Square canvas, transparent background outside the mark, no text or lettering anywhere in the image.
Avoid: photorealistic TV/camera equipment, cartoon mascots, any text/letters/numbers baked into the icon, drop shadows that look like Microsoft Office clip-art, gradient banding, busy/cluttered detail that disappears at 16px.
2. Favicon Set
favicon-16/32/48/64/192/512.png, apple-touch-icon.png
Sizes: 16, 32, 48, 64, 192, 512px square (apple-touch-icon: 180×180) Format: PNG
Used in: browser tabs, bookmarks, mobile home-screen icons, PWA manifest. No separate prompt needed — these are all the same Logo Icon (#1) above, simply exported/resized at each dimension.
