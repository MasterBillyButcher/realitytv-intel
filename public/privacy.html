Privacy Policy

Last updated: September 2026

This page explains what Reality TV Intel does and doesn't do with information, in plain terms.

1. Visitors

Browsing this site as a regular visitor doesn't create an account, and we don't run any third-party analytics, advertising, or tracking scripts. Your browser stores a couple of small local preferences on your own device only: theme (dark/light) and growth-table column display choices, using localStorage. These never leave your device and aren't readable by us.

2. Admin login

The site has one restricted admin account used by the site owner to manage data. Logging in as admin sets a signed, httpOnly session cookie so the browser can't forge or read it. No visitor account system or user sign-up exists on this site.

3. Server logs

Like most web hosting, Vercel (our hosting provider) may log basic technical request data (e.g. IP address, timestamp, requested path) for operating and securing the infrastructure. This site's own code doesn't add any additional visitor tracking on top of that.

4. Third-party data source

Follower-count refreshes are performed server-side through a third-party scraping service (Apify), triggered only by the admin. This lookup sends the public Instagram username being checked to that service; it does not send any visitor's personal information.

5. Cookies

The only cookie this site sets is the admin session cookie described above. There are no advertising or third-party tracking cookies.

6. Children's privacy

This site doesn't knowingly collect personal information from anyone, including children, since it doesn't collect visitor personal information at all.

7. Changes to this policy

This policy may be updated as the site changes. The "last updated" date above reflects the most recent revision.

8. Contact

Questions about this policy can be sent through the site's GitHub repository issue tracker.
